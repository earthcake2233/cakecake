## Reporting a Vulnerability

Please report via **Report a vulnerability** on GitHub Security Advisories, or email
ziyang.wang2006@gmail.com. Do not disclose details in public channels (Issues / Discussions).

We will confirm and fix reported issues as soon as possible, and publish a fix before public disclosure.
